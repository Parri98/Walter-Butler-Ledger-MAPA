# Walter Butler Ledger — Mapa histórico de referencias geográficas

Mapa interactivo elaborado a partir de la transcripción del **Walter Butler Ledger** (102 páginas).

El visor reúne los principales topónimos, puertos, regiones y áreas marítimas identificados en el manuscrito, e incorpora rutas conceptuales desde Waterford hacia algunos de los principales espacios mencionados.

## Contenido

- `index.html` — visor web interactivo listo para GitHub Pages.
- `data/toponimos.csv` — tabla de topónimos utilizada para construir el mapa.
- `.nojekyll` — evita el procesado de Jekyll en GitHub Pages.

## Publicarlo con GitHub Pages

1. Crea un repositorio nuevo, por ejemplo: `Walter-Butler-Ledger-Map`.
2. Sube **todo el contenido de esta carpeta** a la raíz del repositorio.
3. En GitHub entra en **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/ (root)`.
6. Guarda los cambios.

GitHub generará una dirección similar a:

`https://TU-USUARIO.github.io/Walter-Butler-Ledger-Map/`

## Criterio histórico y toponímico

El mapa mantiene las identificaciones establecidas durante el análisis del manuscrito. Cuando una correspondencia moderna no es completamente segura, se indica como **probable**, **aproximada** o con un nivel de seguridad menor. No deben interpretarse las líneas de ruta como reconstrucciones exactas de navegación: son conexiones conceptuales entre Waterford y algunos de los principales espacios documentados.
